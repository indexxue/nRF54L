# ink_panel_console UX 重设计

日期：2026-11-22  
范围：仅 `tools/ink_panel_console`（及必要的 `nrf_console` 桥接小改）；**不改**固件 BLE 协议与页槽语义。  
状态：设计待审（通过后 → writing-plans）

## 1. 意图与成功标准

### 1.1 问题

当前 GUI 是**协议联调台**：暴露 `mode` / `page_id` / BEGIN / flags / SET_GROUP_META 等开发者概念，缺防呆与步骤指引，也缺「填内容出画面」能力。

### 1.2 用户

| 角色 | 优先级 |
|------|--------|
| 产线 / 运营（不懂 BLE 协议） | **主界面默认** |
| 固件开发 / 联调 | **高级**折叠 |

### 1.3 成功标准

1. 不看固件文档也能完成：连接 → 选页 → 填内容或选图 → 推送。  
2. 主界面无 CMD 号、`page_id`、BEGIN、flags、payload 等协议词。  
3. 未满足条件时按钮禁用，并用人话说明原因。  
4. 记事 / 信息可用侧栏表单编辑内容，预览随改刷新，再推到位图。  
5. 开发能力仍在「高级」可用（手动选设备、组 meta、日志、DIY）。

## 2. 已锁定决策

| # | 决策 |
|---|------|
| 受众 | 运营默认 + 高级给开发（C） |
| 主任务 | 推内容/图为主；组标题与页数不挡主路径（C） |
| 连接 | 一键「连接桌牌」；失败再展开手动选设备（C） |
| 选页 | 默认只列 `1..content_count`；高级可「推未启用页并自动加页」（C） |
| 空组 | 「启用组」入口 + 高级自动加页时可边推边启用（C） |
| 推送 | 主「推送并显示」；次「仅保存到设备」（C） |
| 实现路线 | 就地改 CustomTkinter IA，不换技术栈（方案 1） |
| 内容编辑 | 记事「今日三件事」+ 信息「门牌状态」；首页仍导入/模板图（C） |

## 3. 信息架构

```
顶栏：标题 | 步骤条 ①连接→②选页→③编辑/选图→④推送 | [连接桌牌] 状态
左栏：目标页（首页 / 记事标题+页钮 / 信息标题+页钮；空组→启用）
中栏：当前模板表单（随选页切换）或「导入图片」次要入口
右栏：400×300 预览 | [推送并显示] [仅保存到设备] | 下一句指引
底栏：人话状态；可展开「详细日志 / 高级」
```

原则：主区只说「桌牌 / 页 / 内容 / 推送」；协议细节只进高级与详细日志。

## 4. 防呆与步骤

### 4.1 按钮启用条件

| 条件缺失 | 推送按钮 | 状态文案方向 |
|----------|----------|--------------|
| 未连接 | 禁用 | 请先连接桌牌 |
| 无选页 | 禁用 | 请选择要更新的页 |
| 无预览（无表单渲染且无导入图） | 禁用 | 请填写内容或导入图片 |
| 上传中 | 全锁 | 正在推送… |
| 设备忙（ACK 忙） | 可重试 | 桌牌正忙，等刷新完成再试 |

### 4.2 选页规则（默认）

- 首页：单一目标「首页」。  
- 记事 / 信息：仅 `1..content_count`；标题来自 SLOT_STATUS，空则显示「记事」「信息」。  
- `content_count == 0`：无页按钮；显示「启用记事/信息」。

### 4.3 空组启用

- 记事默认启用 **3** 页；信息默认 **2** 页。  
- 写 4001 SET_GROUP_META → 等/拉 8002 → 刷新页钮 → 自动选中第 1 页。  
- 高级「允许推未启用页」开启时：推到 `page > count` 前可先抬 count（或依赖固件 store 抬高，工具侧仍应显式 SET 以保持 UI 一致——实现计划里定一种并写死）。

### 4.4 推送

- 「推送并显示」→ `show=1`。  
- 「仅保存到设备」→ `show=0`。  
- 成功人话：「已更新并显示：记事 · 第 2 页」；不提 CMD。

## 5. 连接状态机

```
空闲 → 扫描中 → 连接中 → 已连接 → 读 SLOT_STATUS → 就绪
         ↓无设备/失败
       人话错误 → 空闲（可重试）
断连/丢失 → 空闲 +「请约 1 秒后再连接」
```

- 一键：扫 `ink_panel`，连 RSSI 最强；多台时高级可手动选。  
- 8002 因 Notify 未就绪：静默短重试；主状态「正在读取桌牌信息…」。  
- 不对运营展示 UUID / ATT / CMD。

### 5.1 文案字典（主状态）

| 键 | 文案 |
|----|------|
| idle | 未连接 · 点击右上角「连接桌牌」开始 |
| scanning | 正在查找附近的桌牌… |
| no_device | 没找到桌牌。请确认已开机并靠近电脑后重试 |
| connecting | 正在连接… |
| reading | 已连接 · 正在读取桌牌信息… |
| ready_pick_page | 已连接 · 请选择要更新的页 |
| need_content | 已选页 · 请填写内容或导入图片 |
| ready_push | 就绪 · 可以推送到「{group} · 第{n}页」 |
| pushing | 正在推送到桌牌，请稍候… |
| ok_show | 已更新并显示：{group} · 第{n}页 |
| ok_save | 已保存到设备（当前屏幕未切换） |
| busy | 桌牌正忙，请等屏幕刷新完成后再试 |
| disconnected | 已断开。请稍等约 1 秒后再连接 |

实现上集中在 `app/copy.py`（名称可微调），禁止魔法字符串散落。

## 6. 内容编辑（Host 渲位图）

固件不描字；工具用模板把表单渲成 BW/RED 平面后走现有上传。

| 目标 | 默认模板 | 字段 |
|------|----------|------|
| 记事页 | 今日三件事 | 页标题；事项 1/2/3；可选「红强调第几条」 |

- 「导入图片」为次要；可覆盖当前预览。  
- 中文字体：工具解析系统 CJK 字体或附带授权字体路径（计划阶段选定一种；缺字体时人话提示，不静默方框）。  
- DIY（nrf_console）留在高级。

### 8.3 验收清单

1. 未连接时推送禁用且有原因。  
2. 一键连接成功后出现页列表或空组启用入口。

6. 「仅保存」不切当前屏（板端行为与现固件一致）。

## 11. 附录：页码 / 首页叠层 / 删页（2026-11-22 补）

### 11.1 已锁定

| 项 | 约定 |
|----|------|
| 内容页页码 | 工具渲进该槽位图，只显示「第 N 页」，**不印总页** |
| 总页/概况 | 放在**首页叠层**，由 MCU 读 meta 填数 |
| 首页底图 | 整帧写一次；不因页数变化重推底图 |
| 叠层开关 | 工具中文勾选 → 写入 **NVS**；MCU 刷 home 时按开关叠数据 |
| 电量 | MCU **占位**（如 `--`），暂不读硬件 |
| 工具角色 | 只做勾选与中文 UI；数值不由工具填进叠层文案 |
| 删页 v1 | 只删组内**最后一页**：`content_count--` + 清该页 valid；需二次确认 |
| 删页更后 | 任意页删除 + 槽位前移重排 |

### 11.2 实现顺序

1. **工具**：顶栏显示编辑目标 + 设备上报记事/信息页数；内容模板印「第 N 页」；首页编辑区勾选叠层（先本地/发配置 CMD）。  
2. **固件**：NVS 叠层开关 + 刷 home 时 ASCII/占位叠层（页数 + 电量占位）。  
3. **固件+工具**：`DELETE_LAST_PAGE`（或等价）删末页 + 工具按钮。  

### 11.3 验收（附录）

- 编辑信息第 2 页时，预览与上屏含「第 2 页」，无「/总页」。  
- 连上后工具可见记事/信息页数；顶栏能看到当前编辑目标。  
- 勾选「显示页数/电量」写入 NVS 后，再显首页出现占位叠层；不勾则无。  
- 删末页后 count-1，该页不可再选；二次确认防误触。
