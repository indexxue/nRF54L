# eink_tag PN5180 NFC 天线重设计方案

| 项 | 内容 |
|----|------|
| 日期 | 2026-10-11 |
| 芯片 | NXP PN5180（Reader，ISO14443-A / NTAG 读写） |
| PCB | 嘉立创普通 4 层 FR4，标称 1.6 mm |
| 依据 | AN11740、UM11232、现网表 `Netlist_Schematic1_2026-10-11.tel`、串口 JUDGE 结论 |
| 状态 | 方案稿（改版前请按 §7 验收） |

---

## 1. 背景与目标

### 1.1 已验证结论（勿再重复踩坑）

| 现象 / 测量 | 结论 |
|-------------|------|
| `fw` 可读、`TX_RF=1`、`SYS_CFG` 进 Transceive | SPI / 开场软件 OK |
| WUPA 后有 SOF、`rx_len=0` | 无有效卡回波，RF 耦合/失谐 |
| TVDD 开场约 5.04 V（关场 5.11 V） | 供电不是主因 |
| 现线圈约 31.2×27.3 mm，顶底各 6 匝**串联**（等效 12 匝） | L 偏大；工具 C1≈12.8 pF（低于 AN11740 建议 ≥15～20 pF） |
| 在 Rs（`R36/37`、`R38/41`）侧探频 | 开场后应见 **~13.56 MHz**；若见 ~1.4 MHz 先排除示波器欠采样 |

### 1.2 本次改版目标

| 目标 | 指标 |
|------|------|
| 协议 | ISO14443-A：WUPA/REQA → 选卡 → NTAG 读页 / 写页（与现固件路径一致） |
| 读距 | 标签贴合～**10～20 mm** 稳定出 UID（室内无大金属遮挡） |
| 线圈电感 | 实测 **0.9～1.3 µH**（优先贴近 **~1.0 µH**） |
| 匹配健康度 | 工具/实测后 **C1 ≥ 20 pF**，C2 合理可焊 E24/E12 |
| 模式 | **以 Reader 为主**；卡模拟（芯片 ANT1/ANT2 PLM）本阶段不做必选 |
| 工艺 | 嘉立创 4 层可量产；匹配位号尽量兼容现网表拓扑，便于改版只动铜皮+电容值 |

非目标：BLE 天线、片上 NFCT、ISO15693 专用优化（可后续加）。

## 2. 方案对比与推荐

| 方案 | 做法 | 优点 | 缺点 | 推荐 |
|------|------|------|------|------|
| **A. 单层螺旋 + 底层仅过桥** | 顶层完整 N 匝；底层只做引出过桥 | 模型接近 NXP 工具；调谐稳；绕向简单 | 同样外径下 L 略小于双层 | **推荐（默认）** |
| B. 双层串联增强 | 顶底各 N/2 匝串联且**同向增强** | 小面积易凑 L | 易绕反抵消；工具估 L 偏差大 | 仅面积不够时备用 |
| C. 维持 12 匝只改电容 | 继续 6+6 | 不改铜 | 已被实测否定 | **否决** |

**推荐方案 A**：外径沿用板级窗口，**单层 4 匝（可 3～5 匝微调）**，底层只过桥。

## 3. 线圈几何（方案 A 默认值）

### 3.1 外形与铜皮

在现有天线窗内尽量铺满（示例按当前窗）：

| 参数 | 推荐值 | 说明 |
|------|--------|------|
| 外形 | 矩形 | 圆角内角 R≥0.3 mm，减尖端场 |
| 外廓 `amax × bmax` | **31.0 × 27.0 mm**（或板窗允许的最大） | 与现窗接近；能加大则优先加大 |
| 匝数 `N` | **4**（首选）；备选 3 或 5 | 目标 L≈1 µH；禁止再上 12 匝串联 |
| 线宽 `w` | **0.50 mm** | 工具常用 ~0.5 mm；损耗与面积折中 |
| 线距 `g` | **0.50 mm** | 勿 <0.3 mm（自谐过低） |
| 铜厚 | 外层 **1 oz（35 µm）** | 与嘉立创常规一致 |
| 层 | **L1 走完整螺旋**；L4 **仅过桥/引出** | 过桥宽度 ≥ 线宽 |
| 过孔 | 过桥处 ≥2 个孔并联 | 降接触电阻 |

### 3.2 NXP Antenna Design Tool 填写（改版前预估）

| 字段 | 填值 |
|------|------|
| IC | PN5180 |
| Dielectric | FR4 |
| `εr` | 4.3 |
| Track thickness | 35 µm |
| PCB Thickness | 1.6 mm |
| Turn Exponent E | 1.65 |
| Additional overlap A | 0（仅过桥、无大面积跨线） |
| Length / Width | 31.0 / 27.0 mm（按实铜） |
| Track width / Gap | 0.50 / 0.50 mm |
| Number of turns | **4** |

跑 **Antenna Synthesis** 后检查：

- 估算 L 落在 **0.9～1.3 µH**；
- 再跑 Matching：固定 **L0 = 470 nH**（与现 `L10/L11` 一致）；
- 接受条件：**C1 ≥ 20 pF**，C0/C2 可用 1～2 颗并联凑齐。

若不满足：先 **N=3** 或略增外径，再重跑；不要靠把 C1 压到 <15 pF「硬凑」。

### 3.3 绕向与禁区（必须）

```text
禁止：
  - 螺旋内侧大面积铺铜 / 十字花铜
  - 天线窗正下方整片 GND（4 层板：L2/L3 在天线投影区开窗或稀疏）
  - 顶底双螺旋串联却绕向相反（磁场抵消）
  - SPI / 高频时钟走线贴着线圈边框内侧穿过

允许：
  - 线圈外侧完整地平面（距外廓 ≥ 2～3 mm 再铺）
  - 匹配器件紧贴 PN5180 TX1/TX2，远离线圈中心
```

## 4. 匹配与接收网络（兼容现网表）

拓扑保持现板 **对称 EMC + 串/并匹配**（与 AN11740 / 现 `L10/L11` 一致）：

```text
TX1 ── L0(L10) ──┬── C1 ──┬── Rs ── 线圈A
                 C0       C2
                 │        │
                GND      GND

TX2 ── L0(L11) ──┬── C1 ──┬── Rs ── 线圈B
                 C0       C2
                 │        │
                GND      GND
```

### 4.1 固定件（改版可不动封装）

| 位号 | 值 | 角色 |
|------|-----|------|
| `L10` `L11` | **470 nH**（高 Q，如 0603 绕线/多层高频电感） | L0 / EMC |
| `C58` `C71` | **1.5 pF** NPO | RXP/RXN 耦合 |
| `R35` `R39` | **4.7 kΩ**（可调） | RX 串联；读卡-only 可按 AGC≈600 微调 |
| `R34` `R40` | **NC** | 需要再衰减再贴 |
| `C63` `C67` | **NC** | 调谐余量焊盘保留 |

### 4.2 随工具结果改值的位号（改版丝印保留并联位）

| 角色 | 位号（左 / 右） | 改版策略 |
|------|-----------------|----------|
| C0 | `C61+C62` / `C65+C66` | 保留双电容并联位，按工具凑 C0 |
| C1 | `C59+C60` / `C69+C70` | 保留并联位；**目标单边合计 ≥20 pF** |
| C2 | `C64`（+可选并联）/ `C68` | 按工具；建议保留一颗空位 |
| Rs | `R36`（`R37` 可并联）/ `R38`（`R41` 可并联） | 单电阻优先；功率不够再并联 |

> 具体 pF/Ω **以 N=4 跑工具的输出为准**，贴片前用下表记录，避免再按 12 匝旧数焊接。

| 参数 | 工具输出 | 实焊组合 |
|------|----------|----------|
| C0 | | |
| C1 | | |
| C2 | | |
| Rs | | |

### 4.3 芯片 ANT1 / ANT2（脚 23/24）

| 模式 | 处理 |
|------|------|
| **仅 Reader（本阶段）** | `C57`/`C72` **NC**，ANT1/ANT2 悬空（勿接地） |
| 将来要 Card / PLM | 再按 AN11740 / 评估板补电容，测阻抗时按手册考虑 ANT1–ANT2 |

### 4.4 电源与布局（继承现设计）

- TVDD **5 V** 常供电；TX 附近 **100 nF + ≥10 µF** bulk（现 `C49/C54` 一类保留）。
- `L0/C0` 紧贴 PN5180；线圈到 Rs 的差分走线尽量对称、短。
- 晶振 **27.12 MHz**（`X3`）远离线圈窗。

## 5. PCB / 嘉立创工艺检查单

- [ ] 天线投影区：L2/L3 **开窗或禁止实心铺铜**
- [ ] 线圈仅 L1 螺旋 + L4 过桥；无顶底双 6 匝串联
- [ ] 线宽/线距按 §3.1，阻抗不按 50 Ω RF 线规理解（这是近场线圈）
- [ ] 匹配电容：**NPO/C0G**，耐压 ≥ 50 V 更稳妥
- [ ] Rs 封装功率余量（0603 起步；热功率不够用两颗并联）
- [ ] 天线窗与 BLE 天线分区，避免重叠
- [ ] 出 Gerber 前在工具重填**最终**铜皮尺寸再导出匹配值

## 6. 软件侧（本改版可不改代码）

现有 `pn5180_port.c` TypeA 扫卡 / JUDGE 可直接用于验收：

- 开扫：`TX_RF=1`，`TS` 合理；
- 贴 NTAG：出现 UID / 不再长期 `WUPA no RX`；
- 可选：读页 / 写页（业务层已有或后续加）。

固件问题已基本排除；**本方案以硬件改版为主**。

---

## 7. 验收步骤

1. **空载开场**：Rs 或 TX 侧示波器（×10、短地、高采样）见 **~13.56 MHz**。  
2. **电感（可选）**：匹配断开，LCR @100 kHz 测线圈 **0.9～1.3 µH**；无 LCR 则依赖工具 + 步骤 3。  
3. **贴卡**：BTN 开扫，串口出现 TypeA UID；读距达到 §1.2。  
4. **读写**：对 NTAG 读 4 页 / 写 1 页成功（按产品用例）。  
5. **回归**：TVDD 开场压降仍小；BLE 广播与扫卡可分时共存（现架构已分线程）。

失败分流：

| 现象 | 动作 |
|------|------|
| 无 13.56 MHz | 查晶振 `X3`、TVDD、`rf_on` |
| 有 13.56、仍无 RX | 查匹配值是否按 **N=4 新结果**焊接；查铺铜开窗 |
| C1 工具仍 <20 pF | 减匝或加大外径，禁止沿用 12 匝思路 |

## 9. 决策摘要

- **做**：单层约 **4 匝**、线宽/线距 **0.5/0.5 mm**、目标 **L≈1 µH**、**C1≥20 pF**、Reader 优先、ANT1/ANT2 电容先 NC。  
- **不做**：顶底 6+6 串联、内侧铺铜、只靠把 C1 压到 12 pF「救」12 匝。  
- **匹配拓扑与位号**：尽量沿用现网表，只改几何与电容/电阻值。

若板窗尺寸有硬限制（小于 28×24 mm）或必须双层，再开方案 B 并强制实测 L + 绕向检查。

## 10. 现成可抄线圈（≤30 mm）

### 10.1 官方有没有「整板 Gerber」可抄？

| 来源 | 尺寸 | 能否直接抄进本板 |
|------|------|------------------|
| OM25180 / PNEV5180 **65×65 mm** 评估天线 | 超 30 mm | 否（太大） |
| 套件附带 **30×50 mm** NFC 天线板 | 一边 30、一边 50 | **整板超限**；仅可参考「少匝 + 外置匹配」思路 |
| AN11740 / Antenna Tool | 给尺寸–匝数经验，**无开源 Gerber** | 按下表抄**参数**画铜 |

结论：**≤30 mm 没有可直接下载的官方 Gerber**；下面给出可直接填工具 / 画 PCB 的抄作业参数。

### 10.2 推荐直接抄（单层 + 底层过桥）

**首选（正方形，最大边 28 mm）：**

| 参数 | 抄这个 |
|------|--------|
| 外廓 | **28.0 × 28.0 mm** |
| 匝数 N | **4**（单层） |
| 线宽 w | **0.50 mm** |
| 线距 g | **0.50 mm** |
| 层 | L1 螺旋；L4 只过桥 |
| 铜厚 | 35 µm（1 oz） |
| 工具其它 | FR4，εr=4.3，板厚 1.6 mm，E=1.65，A=0，IC=PN5180 |
| L0（匹配） | **470 nH**（现 `L10/L11`） |

**备选（矩形，最大边 30 mm）：**

| 参数 | 抄这个 |
|------|--------|
| 外廓 | **30.0 × 25.0 mm** |
| 匝数 N | **4** |
| 线宽 / 线距 | **0.50 / 0.50 mm** |
| 其余 | 同首选 |

**面积更紧（最大边 ≤25 mm）：**

| 参数 | 抄这个 |
|------|--------|
| 外廓 | **25.0 × 25.0 mm** |
| 匝数 N | **5**（仍单层；不要上到 8～12） |
| 线宽 / 线距 | **0.40 / 0.40 mm** |
| 其余 | 同首选；跑工具后确认 **C1≥20 pF**，否则改 N=4 并略放宽间距 |

### 10.3 抄完后唯一必做

1. 用上表跑 NXP Antenna Synthesis → Matching（L0=470 nH）。  
2. **按新 C0/C1/C2/Rs 改焊**，不要沿用 12 匝那组电容。  
3. 天线投影区 L2/L3 **开窗**；`C57/C72` Reader 阶段可 NC。

### 10.4 可买现成小板（可选验证，非抄铜）

若只想先验证读卡：买 PN5180 套件里的 **30×50 mm** 外置天线板，飞线到本板 `TX` 匹配后节点做对照。确认软件/电源 OK 后，再把 **§10.2 首选** 画进自己的 ≤30 mm 窗。
